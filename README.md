# 🤔 What is this?

**Trick Questions** is a fun browser game built using **Python** and **Streamlit**.

The questions are designed to trick your brain by making you think the obvious answer is correct...

...until it isn't 😅

Some questions will make you laugh.

Some will make you question your intelligence.

Some might make you rage quit. 😂

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
```

Go inside the folder

```bash
cd REPO_NAME
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the app

```bash
streamlit run app.py
```

Place correct-answer sounds in `correct_audio/` and incorrect-answer sounds in
`incorrect_audio/`. Supported formats are MP3, WAV, OGG, and M4A. A random
sound from the matching folder plays after each answer; the original sounds in
the project root are used if a folder is empty.

Open

```
http://localhost:8501
```

# 🎯 How to Play

1. Click **Start Game**
2. Read the trick question carefully
3. Choose one of the four answers
4. Try not to get fooled 😄
5. Beat your previous score!
